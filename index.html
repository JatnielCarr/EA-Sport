Módulos del proyecto

Estructura completa del sistema

Cada tarjeta representa un módulo independiente del proyecto. Haz clic para navegar a cada área.

🖥️
Admin Frontend
Panel de administración construido con Vite. Gestión de torneos, brackets, equipos y resultados con interfaz reactiva.
fronted/index.html
👤
User Portal
Portal de usuario final con autenticación Firebase, perfil, clanes, favoritos, notificaciones y soporte PWA con Service Worker.
FrontedUser/index.html
📱
Mobile App
Aplicación móvil React Native con Expo. Componentes reutilizables, navegación y acceso a todas las funcionalidades de la plataforma.
mobile/ (React Native)
⚡
Backend API
API RESTful con Fastify + TypeScript. Autenticación JWT, rutas de torneos, equipos, partidas y resultados. Documentación Swagger integrada.
src/ (Fastify + TypeScript)
🗄️
Base de Datos
Esquema Prisma con PostgreSQL. Modelos de usuarios, torneos, equipos, partidas, brackets y suscripciones Stripe. Migraciones versionadas.
prisma/schema.prisma
🤖
Automatización n8n
Workflows n8n para notificaciones automáticas, webhooks de Stripe, bot de Discord y orquestación de eventos del torneo.
apex-bot-n8n-workflow.json
🛠️
Scripts de Utilidad
Colección de scripts TypeScript/JS para setup inicial, seeds de datos, configuración de Stripe, webhooks, generación de equipos y depuración.
scripts/
📬
Colección Postman
Colección completa de pruebas de API con Postman. Entorno preconfigurado y guía de uso para probar todos los endpoints del sistema.
Postman-pruebas/
✅
Tests
Suite de tests con Jest y Supertest. Pruebas de integración para autenticación, torneos y endpoints críticos de la API.
tests/ (Jest + Supertest)

API Reference

Endpoints principales

Todos los endpoints siguen el esquema REST. La documentación completa está disponible en /documentation (Swagger UI).

Método Ruta Descripción
POST/api/auth/registerRegistro de usuario
POST/api/auth/loginInicio de sesión (devuelve JWT)
POST/api/auth/refreshRefrescar access token
GET/api/tournamentsListar torneos
POST/api/tournamentsCrear torneo
GET/api/tournaments/:idDetalle de torneo
PUT/api/tournaments/:idActualizar torneo
DELETE/api/tournaments/:idEliminar torneo
GET/api/teamsListar equipos
POST/api/teamsRegistrar equipo
POST/api/teams/:id/joinUnirse a un equipo
GET/api/matchesListar partidas
POST/api/matches/:id/resultReportar resultado
PATCH/api/matches/:id/disputeDisputar resultado
POST/api/tournaments/:id/bracketGenerar bracket
GET/api/tournaments/:id/bracketVer bracket
GET/api/tournaments/:id/standingsTabla de posiciones
POST/api/payments/checkoutCrear sesión de pago Stripe
POST/api/webhooks/stripeWebhook de eventos Stripe
